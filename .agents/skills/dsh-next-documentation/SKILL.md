# dsh-next documentation

Follow `docs/AGENTS.md`.

1. Write in English only, without emoji.
2. Keep each fact in its owning document; update docs in the same change that
   changes behavior.
3. Every package keeps a `README.md` with purpose, install, and development
   commands.
4. Run `pnpm docs:check` before merging.
