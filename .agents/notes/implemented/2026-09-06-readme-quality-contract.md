# Package README quality contract

- date: 2026-09-06
- status: implemented
- scope: docs/AGENTS.md, docs/i18n.md, plugin-template, documentation skills

Package READMEs are first-run guides, not contributor handbooks. Owning
rules: `docs/AGENTS.md` (tone, shape, screenshots, npm install). GitHub vs
npm links: `docs/i18n.md`. Skills point at those docs; the plugin scaffold
drops the Development `pnpm` block and uses the npm install form.
